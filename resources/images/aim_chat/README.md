# AIM decorative illustrations

The runner and smiley are isolated illustrations exported at 2× resolution from the local `mocks.html` AIM design. The computer and folder are original 40×32 pixel illustrations, rendered with point filtering. No window chrome, chat text, or controls are baked into these images. Window borders, title gradients, all labels, chat history, the optional developer-log pane, and composition/editing are native UI.
