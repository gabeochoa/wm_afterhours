# Kart Select decorative artwork

These transparent 2× PNG atlases are Chromium exports of the repo-authored SVG
art in the approved `kart_select` mock in `mocks.html`:

- `portraits.png`: eight 115×125 CSS-pixel racer portraits in a 4×2 atlas.
- `karts.png`: eight 120×75 CSS-pixel kart thumbnails in a 4×2 atlas.
- `big_karts.png`: the same eight karts rendered in the mock's 592×291 preview
  box, in a 4×2 atlas.

Names, statistics, selection badges, buttons, and all other interactive content
remain native UI elements.
