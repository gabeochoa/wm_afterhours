# Who's Who decorative artwork

`portraits.png` is a transparent 2× Chromium export of the 24 repo-authored
portrait SVGs in the approved `guess_who_lab` mock in `mocks.html`. Each atlas
cell represents the mock's 128×84 CSS-pixel portrait area. `logo.png` is an
isolated 2× export of the mock's decorative title treatment using the embedded
Fredoka font from `output/mocks-standalone.html`.

Card names, note selectors, question controls, counts, and all hit targets
remain native UI elements.
