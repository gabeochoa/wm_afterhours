# Mobile settings artwork

Decorative artwork exported at 2× resolution from the `casual_settings` and
`angry_birds_settings` designs in `mocks.html`: the forest SVG, empty board,
empty blue and green button plates, and music, sound, vibration, wireless, and
close icons. Button plates include transparent padding for their shadows. No
text or complete interface screenshot is baked into these assets. Native
widgets supply all labels, hit targets, focus, and state changes.

`forest.svg` preserves the original vector source. The PNGs were rendered in
Chromium from the corresponding SVG and CSS elements with text and unrelated
page content removed. The shared native typeface is
`resources/fonts/Fredoka-MockBold.ttf`; its license and generation details live
with that font.
