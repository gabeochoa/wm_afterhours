# Marlo Kart decorative art

Exported at 2× resolution from the original CSS/SVG illustrations in this repository’s `mocks.html` Marlo Kart design. The exports contain scenery, empty header/footer plates, portraits, kart illustrations, and a trophy; they contain no UI labels, controls, or game-state text. Native UI renders all text and controls. The track preview and race minimap are native drawings of the same `TrackShape` used by physics.

The illustrations are original local mock artwork, not Nintendo assets. `portrait_0` through `portrait_7` and `kart_0` through `kart_7` follow the native driver order. Images are drawn with bilinear filtering at the current screen-height scale. The title/race/selection scene uses the driver’s selected illustration while native stats, lap count, rankings, items, countdown, and points remain live.
