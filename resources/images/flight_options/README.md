# Flight options atmosphere

`airspace.png` contains only the background gradients, haze, grid and decorative
wire paths from the `flight_options` design in `mocks.html`. `selection.png` is
the empty category highlight, with transparent padding for its glow. Both were
rendered from isolated CSS/SVG elements at 2× resolution in Chromium. Neither
contains text or a complete interface screenshot. All labels, navigation,
setting values, hit targets, focus and state changes are native widgets.
