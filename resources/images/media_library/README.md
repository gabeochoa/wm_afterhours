# Media Library decorative art

Six label-free poster illustrations and a background gradient exported at 2× resolution from this repository’s original `mocks.html` artwork. The original mock cycles these six illustrations across the 24 library records. All poster titles and taglines, item labels, metadata, ratings, state, filtering, and controls are native UI; no screen or card text is baked into an image. The original 24 native item records are retained.
