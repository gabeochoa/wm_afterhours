# Kirby options decorative artwork

The desk, empty board/grid, notebook, empty name/delete plates, icon tabs,
option icons and small label/underline plates were isolated from the
`kirby_options` design in `mocks.html` and rendered in Chromium at 2× resolution.
The profile silhouette, notebook doodles and interface symbols are decorative
icons. Text labels, profile names, values, selection, hit targets, focus and
editing are all native widgets; no complete interface screenshot is used.

`layout.json` records each isolated element's source bounds and export padding.
The broad board surface retains the common grid's rules as decoration. The
native detail view replaces that grid with live controls when opened.
