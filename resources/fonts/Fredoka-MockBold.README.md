# Fredoka Mock Bold

`Fredoka-MockBold.ttf` is a static instance of
`Fredoka-VariableFont_wdth,wght.ttf`, generated with fontTools
`instantiateVariableFont` at `wght=700` and `wdth=100`. It is loaded as
`FredokaMockBold` with a 96 px raster size for the mobile game mock screens.

The font remains covered by the SIL Open Font License in `OFL.txt`; its source
copyright is held by The Fredoka Project Authors.
